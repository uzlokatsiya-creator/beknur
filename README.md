# Doktor Ismati — shaxsiy brend sayti

3 tilli (UZ / RU / EN) sayt + admin panel.

## Ishga tushirish
```
npm install
ADMIN_PASSWORD=yangiParol npm start
```
- Sayt: http://localhost:3000
- Admin: http://localhost:3000/admin/ (standart parol `admin123` — albatta o'zgartiring)

Ma'lumotlar `data/data.json` da, yuklangan rasmlar `public/uploads/` da saqlanadi.
